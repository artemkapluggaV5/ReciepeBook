# Первое заполнение сайта

`storefront.json` — снимок публичного каталога локального сайта с ценой 1990 ₽.
Он не содержит заказов, пользователей, секретов и закрытого PDF.

Загружайте только при первом запуске с пустым каталогом:

```bash
docker compose cp products/fixtures/storefront.json web:/tmp/storefront.json
docker compose exec web python manage.py loaddata /tmp/storefront.json
```

Повторная загрузка перезапишет товары и связанный контент с теми же ID.
Загрузка не включает продажи: платёжные реквизиты, SMTP и приватный PDF
настраиваются отдельно. Снимок сохраняет демонстрационный статус товара.
