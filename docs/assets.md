# Изображения и происхождение

Все три фотографии сгенерированы встроенным инструментом ImageGen 27.10.2026 для этого проекта. Сторонние фотографии, бренды, портреты и логотипы не использованы. Это иллюстрации демонстрационных блюд; они не подтверждают фактический состав PDF. Владелец должен проверить рецептуры, права на конечный контент и при необходимости заменить изображения своими. В production сайт не зависит от удалённых URL изображений.

| Локальный файл | Назначение |
|---|---|
| `static/img/food.webp` | Тёплый салат: hero, обложка-концепция и первая карточка |
| `static/img/pasta.webp` | Паста с томатами: вторая карточка |
| `static/img/galette.webp` | Галета с грушей: третья карточка |

WebP оптимизированы для web: первая фотография 1440×960, остальные до 900×900. Обложка и разворот собраны HTML/CSS; это не выданный за настоящую книгу скан. Favicon — собственный простой SVG-знак, без сторонней библиотеки иконок. Шрифты системные, внешних загрузок нет. Иконки интерфейса теперь собственные inline SVG, Apple touch PNG создан из той же простой геометрии; шрифтовые значки не используются.
