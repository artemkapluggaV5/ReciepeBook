# Финальная доводка интерфейса

Контрольная точка перед правками: `e52cd8e` на ветке `design/holiday-cookbook`. Сохранены все предыдущие изменения.

## Изменения

- `static/css/holiday.css`: единая шкала 16/14/12 px для текста интерфейса; увеличены навигация, пояснения, описания рецептов, FAQ, согласие и подвал. Миниатюрная типографика концепции обложки сохранена как часть иллюстрации; её поясняющая подпись теперь читается отдельно.
- Карточки получили согласованные пропорции изображений, более компактные равные отступы, выравнивание ссылок, состояния hover/focus. На планшете изображение и текст расположены рядом, на телефоне — друг под другом.
- Уточнены переносы на 320 px, поля и кнопки, отступы цены и заметность честных тестовых уведомлений. Контур фокуса на тёмном hero сделан светлым. Движение остаётся лёгким и отключается через существующие правила reduced motion.
- `templates/landing.html`: одно пояснение о PDF, подтверждении оплаты и доставке на email рядом с ценой. Форма, CSRF, поля, nonce, action и загрузочное поведение не изменены.
- `templates/base.html`: версия CSS в URL по хешу содержимого, чтобы ранее открытый предпросмотр не продолжал показывать старую тему из кеша. Production-хеширование static сохранено.

Новые библиотеки, изображения, шрифты и JavaScript не добавлены. Концепция первого экрана, палитра, фотографии и структура содержания сохранены. База и настройки не редактировались, команды изменения демопродукта при этой доводке не запускались.

## Проверки

- `manage.py check`: без замечаний. `makemigrations --check --dry-run`: изменений нет. `collectstatic --noinput`: успешно.
- PostgreSQL 18.1: все **60 тестов** прошли без пропусков. SQLite: 57 прошли, три проверки конкуренции пропущены по назначению. В тестах используются фиктивные платёжные данные и локальный email backend.
- SHA-256 для 41 защищённого файла совпал с исходной контрольной суммой: Robokassa, заказы, доставка, конфигурация/маршруты, модели/Admin, прежний JavaScript и private PDF не изменены.
- Браузерный просмотр 320, 375, 390, 430, 768, 1024, 1440 px и промежуточных границ: без горизонтального переполнения. Проверены главные секции, фотографии, размеры inline SVG, поле email 16 px, отсутствие потерянных якорей.
- Меню открывается и закрывается по Escape с возвратом фокуса; все шесть FAQ и рецепт открываются с клавиатуры. Неверный email блокируется браузером без отправки формы; кнопка не зависает в загрузочном состоянии. Серверная валидация и платёжные сценарии покрыты существующим набором тестов.
- До и после сохранены отдельные снимки desktop/mobile. Открытый статический предпросмотр обновлён; в нём нет форм, Admin или доступа к private PDF.

## Ограничения

Настоящий Safari/iPhone в среде недоступен. Lighthouse не запускался; показатели Core Web Vitals не измерялись, полный аудит доступности не выполнялся. Требуется проверка на реальном iPhone, особенно safe-area, ввод с экранной клавиатурой и сохранение PDF. Живые платежи Robokassa и доставка через реальный SMTP не выполнялись; тестовые ограничения сохранены. Для запуска продаж по-прежнему нужны реальный проверенный PDF, содержание и обложка, реквизиты, юридические документы, Robokassa и SMTP, затем сквозная проверка.
