# Раскрытие примеров внутри карточки

Сохранён обычный HTML `<details>`: он работает без JavaScript, с клавиатуры и на телефоне. Рецепт раскрывается внутри своей карточки, соседние карточки больше не растягиваются. Ингредиенты оформлены списком, приготовление — нумерованными шагами.

При открытии единственный переключатель сверху меняется на «Свернуть пример», плюс — на крестик. Дополнительных кнопок и JavaScript для рецептов нет. Модального окна и блокировки фоновой страницы нет.

Платёжная логика, формы, данные рецептов, private PDF и существующий `site.js` не менялись. Реальный iPhone Safari недоступен и требует отдельной проверки на устройстве.
