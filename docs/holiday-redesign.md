# Новогодняя презентация

Редизайн существующего проекта на ветке `design/holiday-cookbook`. Исходный Git checkpoint: `adea622`. Сохранены существующие маршруты, формы, JavaScript, iOS-совместимый CSS и конфигурация.

## Что изменено

- `templates/base.html`, `templates/landing.html`: праздничные тексты, метаданные, концепция обложки, честные демонстрационные подписи. Canonical оставлен прежним.
- `static/css/holiday.css`: отдельный слой лесного зелёного, бордо, айвори и золота; адаптивная композиция и лёгкое появление с учётом reduced motion.
- `static/img/holiday-*.webp`: четыре локальных иллюстративных изображения, всего около 740 KiB. Происхождение и промпты: [holiday-assets.md](holiday-assets.md).
- `products/management/commands/apply_holiday_theme.py`: обновление представления активного демопродукта через существующие модели. Перед изменением записывает JSON-копию в игнорируемый `work/`. Не переписывает реальные товары, цену, валюту, количества, путь PDF, загруженные обложки/изображения и подтверждённые рецепты.
- `tests/test_holiday_presentation.py`: две проверки сохранения коммерческих данных и реального контента; README дополнен командой первого запуска темы.

Установить демопрезентацию после `seed_demo`: `python manage.py apply_holiday_theme`. Повторный запуск создаст новую резервную копию. Свою обложку, описание, главы, рецепты и настоящие превью редактируйте через существующий Django Admin. Не выдавайте демонстрационные рецепты и макет за содержимое PDF.

## Проверки

- Django `check`: без замечаний; `makemigrations --check --dry-run`: изменений нет; `collectstatic`: успешно.
- Все 60 тестов прошли на PostgreSQL 18.1, в том числе три проверки конкурентных операций, подписей YooKassa, суммы/валюты, повторов callback, CSRF, защищённого скачивания и отказа/повтора email. На SQLite: 57 прошли, 3 проверки конкуренции пропущены.
- Контроль SHA-256 для 41 защищённого файла, включая payment/order/delivery/config, модели/Admin, маршруты и существующий private PDF: совпадает с состоянием до редизайна. Приватный PDF не входит в распространяемый архив.
- Браузерный просмотр на 320, 375, 390, 430, 768 и 1440 px: без горизонтального переполнения. Проверены мобильное меню, клавиатурное раскрытие рецепта и FAQ, локальные изображения и SVG, наличие CSRF и прежний action формы `/checkout/`, размер поля email 16 px. Иконка скрытой мобильной ссылки навигации ожидаемо имеет нулевой размер.
- Сохранены safe-area, inline SVG, совместимые шрифты, fallback изображений и прежний JavaScript. Новых внешних библиотек нет.

Тесты используют поддельные учётные данные и локальный email backend; они не доказывают работу живого эквайринга/SMTP. Реальные платежи не выполнялись. Safari/iPhone в этой среде недоступен: перед запуском проверьте реальный iPhone (иконки, safe-area, клавиатуру и форму, сохранение PDF), затем собственный тестовый магазин YooKassa и SMTP. Их настройка описана в README и существующих документах.

## Перед публикацией продаж

Владелец должен предоставить настоящий PDF и обложку, проверить рецептуры и их соответствие книге, фактический состав/объём/цену, реквизиты продавца, контакты и юридические тексты. Реальный PDF и платёжные данные автоматически не менялись. Открытая ссылка для показа ведёт на статический предпросмотр без оформления заказов и Admin; её адрес временный и зависит от работающего компьютера.
