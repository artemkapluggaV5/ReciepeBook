# Структура витрины от 5 ноября 2026

Приветствие → история → сборник и цена → содержание → бесплатные примеры →
форма покупки → FAQ → слайдер отзывов / иллюстраций → Telegram → юридические ссылки.

Стили нового оформления: `static/css/cozy.css`, скрипт слайдера: `static/js/cozy.js`.
Слайдер без автопрокрутки: свайп, кнопки, стрелки клавиатуры, Home/End.
Без JavaScript остаётся горизонтальная прокрутка с фиксацией на слайдах.

## Материалы владельца

- Загрузить обложку в карточку продукта. Пока показана концепция с иллюстрацией.
- Отзывы: Админка → Products → сборник → Отзывы. Указать имя, текст и необязательное фото.
  Публикуются только записи с отметкой «Разрешение на публикацию получено».
  Перед загрузкой скриншотов удалить чужие номера телефонов и другую личную информацию.
  Пока нет разрешённых отзывов, показана галерея из трёх иллюстраций с явной подписью,
  что это не отзывы. Фальшивые отзывы не добавляются.
- Telegram: добавить в `.env` `TELEGRAM_USERNAME=имя_аккаунта` без `@` и ссылки,
  перезапустить Django. Пока значение пустое, отображается уведомление и email.
- Приветствие и история редактируются в `templates/landing.html`.
  Для портрета авторов нужны собственные фото и согласованный текст о них;
  в текущей версии использован коллаж блюд без вымышленных авторов.

После обновления выполнить `python manage.py migrate`: добавлена таблица отзывов.
Коммерческие параметры и логика ЮKassa/доставки этим обновлением не менялись.
Живые платежи и SMTP требуют отдельной настройки и реальной проверки.
