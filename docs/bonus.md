# Подарочный сборник

`marishkiny-retsepty.pdf` хранится только в приватном Docker volume `/app/private`.
PDF не входит в Git и Docker image. Контрольная сумма утверждённого файла записана
в `products/bonus_release.json`.

После `git pull --ff-only origin main` и `docker compose up -d --build`
миграция `0005_set_cookbook_price_1590` один раз устанавливает цену
основного активного сборника 1590 ₽ независимо от наличия подарочного PDF.

Для подарка загрузите
оригинал PDF через SFTP в `/root/marishkiny-retsepty.pdf`, затем:

```bash
docker compose cp /root/marishkiny-retsepty.pdf web:/app/private/marishkiny-retsepty.pdf
docker compose exec -T web python manage.py connect_bonus --price 1590
```

Команда проверит SHA-256, подключит подарок и установит цену 1590 ₽ у единственного
активного товара. При нескольких товарах требуется `--product-id`. Настройки оплаты
и суммы ранее созданных заказов не меняются. Цена и поля подарка затем редактируются
в карточке товара в Admin.

Подарок обозначен перед оплатой. После подтверждения платежа на странице заказа
появляется отдельная кнопка «Скачать подарок». Оба файла требуют сессию владельца
оплаченного заказа и подписанный токен. Срок, отзыв доступа при возврате и общий
лимит скачиваний применяются к обоим файлам. Старые ссылки на основной PDF работают
по прежним правилам. Если файл подарка настроен, но исчез, новые платежи блокируются,
а на странице уже оплаченного заказа появляется сообщение поддержки.
